# 四喵对话生成器 · 独立可编辑版

React + TypeScript + Vite 项目，所需图标、表情和默认头像均包含在本目录内，不依赖原 simiaoChat 目录。

## 启动

需要 Node.js 20.19+。

```sh
npm ci
npm run dev
```

## 构建

```sh
npm run build
npm run preview
```

构建生成单文件 `dist/index.html`（约 2 MB），脚本、样式、图标、表情及默认头像均内嵌。可以直接发送此文件，接收者保存后用桌面浏览器打开，无需安装 Node.js 或启动服务器。也支持上传到静态托管服务。

上传的头像、图片和聊天草稿保存在当前浏览器中，不会自动写回 HTML 文件，也不会随 HTML 发送给其他人。

## 目录

- src/：编辑器、聊天预览、样式、草稿数据模型
- assets/icon/：深浅模式和语音图标
- assets/emoji/：108 个表情资源
- public/media/：默认头像

支持文字、图片、语音、时间消息；角色编辑；深浅模式和气泡配色；状态栏设置；固定高度与消息滚动；3 倍 PNG 导出。草稿自动保存在当前浏览器，域名或端口变化后不会自动同步。
